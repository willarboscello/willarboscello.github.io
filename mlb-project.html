Predicting Whether an MLB Game Will Have 9 or More Runs

Problem Definition

For this project, I wanted to see if I could predict whether an MLB game would have 9 or more total runs. My target variable is runs_9_plus, where 1 means the game finished with 9 or more runs and 0 means it finished with less than 9 runs.

Background and Context

There are a lot of things that can affect how many runs are scored in an MLB game. I looked at things like the teams, venue, weather, and temperature to see if basic pregame information could help predict scoring.

Data Description

The dataset contains 2,464 MLB games from the 2025 season. Each row represents one game. The data includes the home and away teams, venue, score, weather, temperature, attendance, and other game information.

Model Results

I compared a baseline model, logistic regression, and a decision tree. Logistic regression performed the best with about 54.0% accuracy. The decision tree had about 52.1% accuracy, while the baseline had about 51.1%.

Conclusion

The results showed that these basic pregame features had some value, but they were not strong enough to predict scoring very accurately. If I continued the project, I would add more baseball-specific features like starting pitchers, bullpen strength, injuries, and recent team performance.
